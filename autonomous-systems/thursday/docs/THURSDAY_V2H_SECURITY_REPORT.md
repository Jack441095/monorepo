# Thursday V2-H Security Report

## Authority

`SecurityReviewer` holds a hard veto that overrides any QA PASS and cannot be
averaged away or overruled by the producing specialist. It is invoked whenever
changed files match policy-critical patterns, mutation boundaries touch
security-sensitive paths, or QA flags `POLICY_FILE_CHANGED`.

## Policy-critical surfaces

Changes touching any of these trigger mandatory security review:
approval semantics, lease authority, shared executor, token/plan contracts,
sandbox policy, plan approval, confirmation, action receipts.
