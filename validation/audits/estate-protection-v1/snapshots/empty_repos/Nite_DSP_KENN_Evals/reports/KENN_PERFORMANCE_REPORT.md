# KENN Performance Report

Full Mix Review analysis processed 240 × 0.75-second renders in 281.704 s:
1.130 s/case, real-time factor 1.51. Peak observed process RSS was roughly
112 MB during the run. The metering-only path ran in 68.162 s but returned no
flags, so it is not a substitute for recommendation qualification.

No malformed/truncated/NaN format matrix was run in this pass; it remains a
separate robustness expansion, not a hidden pass.
