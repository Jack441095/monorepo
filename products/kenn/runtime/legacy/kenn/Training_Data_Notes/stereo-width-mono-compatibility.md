# Stereo Width And Mono Compatibility

Type: Mixing workflow
Tags: stereo width, width, mono, phase, correlation, haas, mid-side, panning, mixing, translation
Status: Approved

Short answer:
Use stereo width above the low mids and always check mono. Keep kick, bass, lead vocal, and core snare energy centred; widen supporting parts, effects, doubles, and high-frequency texture. If a part vanishes in mono, the widening is too phase-dependent.

Try this:
1. Put low-end elements in the centre before widening anything else.
2. Use panning and arrangement first; use wideners only when panning does not solve it.
3. High-pass widened returns or side information so low mids stay controlled.
4. Be careful with Haas delays: they can sound wide in stereo but collapse badly in mono.
5. Use mid-side EQ gently: cut muddy side low mids before boosting side air.
6. Check the mix in mono and on small speakers after each major width move.

Why it matters:
Width is not just a stereo trick. Good width keeps the mix exciting while still translating on phones, clubs, radio, and mono playback.
