# Group Bus Workflow

Type: Production workflow
Tags: groups, bus, routing, mixing, organization, workflow
Status: Approved

Short answer:
Route related tracks into Group tracks (drums, music, vocals, FX) so you can process and level sections together. Keep sends on individual tracks when you need per-sound space, and use group processing for glue.

Try this:
1. Select related tracks → Cmd/Ctrl+G to create a group; rename immediately (Drums, Bass, Vocals).
2. Put bus compression or saturation on the group for glue, not on every channel.
3. Automate group fader for section dynamics; keep kick/snare inside Drums group for cohesive punch.
4. Color-code groups to match your session template.
5. Freeze heavy groups before final export if CPU is tight.
