# Client Stem Handoff Checklist

Type: Client workflow
Tags: stems, delivery, client, export, mixing, handoff, checklist
Status: Approved

Short answer:
A clean handoff needs labeled stems, one consistent length, agreed sample rate, and a short text file listing BPM, key, and any known issues — plus what is included (wet/dry, with or without FX).

Try this:
1. Confirm in writing: stem list (e.g. kick, snare, bass, instruments, lead vocal, backing vocals), format (WAV 24-bit), and whether FX prints are allowed.
2. In Ableton, solo each stem group and Export → Selected Tracks Only; disable master limiter on the export path.
3. Name files `Artist_Song_element.wav` (no spaces if the client prefers underscores).
4. Export all stems from the same start bar so they line up when imported.
5. Include a `README.txt` with BPM, key, sample rate, and notes (“vocal double only on chorus”, “guitar amp sim on track”).
6. Zip the folder; send a streaming preview (rough mix or reference) if the client needs context before the engineer imports.
7. Keep a copy of the original client archive untouched for dispute/ revision reference.

Why it matters:
Stem confusion causes the most mix delays for Audio_Too. This complements export-stems-for-mixing with client-facing checklist language.
