Short answer:
In Delay's Repitch mode, changing delay time can bend the pitch, which can be used for tape-stop or unstable glitch effects. Fade mode avoids the obvious pitch bend when delay time changes, so the result feels more like time-stretching than repitching.

Key ideas:
- In Delay's Repitch mode, changing delay time can bend the pitch, which can be used for tape-stop or unstable glitch effects.
- Fade mode avoids the obvious pitch bend when delay time changes, so the result feels more like time-stretching than repitching.
- Increasing delay time in Fade mode can stretch the delayed audio; larger time changes make the texture more intense and unstable.
- Fast delay-time movement can create reversed or smeared playback artefacts, which can work well for experimental transitions.
- The Delay modulation section can automate delay-time movement, creating rhythmic speed-up and slow-down effects without drawing automation by hand.
