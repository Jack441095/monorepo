# Home Vocal Recording In Ableton

Type: Recording workflow
Tags: vocal, recording, home, gain, monitoring, workflow, artist
Status: Approved

Short answer:
At home, prioritize clean gain staging, dry monitoring, and short punch-in takes over expensive plugins. Record 24-bit with headroom and fix the room with position and absorption before heavy processing.

Try this:
1. Use one cardioid condenser or dynamic mic; reduce room reflections with a duvet/vocal shield behind the singer.
2. Create an audio track with Input set to your interface; monitor with low-latency, avoid monitoring through heavy reverb.
3. Aim for peaks around -12 to -6 dBFS on the track meter while singing; turn down if clipping.
4. Record multiple short takes (verse, chorus) on separate clips or takes instead of one long pass.
5. Use punch-in (overdub) for fixing lines; crossfade clip edges 5–15 ms to hide edits.
6. High-pass at 80–100 Hz only if rumble appears — do not filter by default on every take.
7. Save the raw recording Set before tuning or heavy compression; send dry WAV if a mixer will work on it later.
