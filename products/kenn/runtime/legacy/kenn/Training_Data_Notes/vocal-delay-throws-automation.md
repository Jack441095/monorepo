# Vocal Delay Throws and Send Automation

Type: Vocal mixing workflow
Tags: vocal delay throw, phrase ending, send automation, delay return, reverb throw, vocal line, gaps, masking, wash
Status: Approved
Source: Audio_Too studio practice
Reviewed: 2026-07-01

Short answer:
Automate the send into a delay or reverb return only on selected phrase endings. Keep the return quiet or muted through the line, then let the throw occupy the gap before the next lyric.

Try this:
1. Put the delay or reverb on a fully wet return track.
2. Set the delay time and feedback so the repeats decay before they mask the next important phrase.
3. Automate the vocal's send level up on the final word or syllable and return it to zero immediately after.
4. High-pass and low-pass the return; de-ess before the effect if consonants trigger sharp repeats.
5. Duck the return from the dry vocal if a long tail must continue underneath the next line.

Why it matters:
A constant effect level pushes the vocal backward and fills every gap. A throw creates audible depth and excitement while preserving dry-vocal intelligibility.

Common mistakes:
- Automating the return fader when several sources share it and unintentionally changing every source.
- Raising feedback without checking whether the repeat overlaps the next lyric.

When this does not apply:
An intentionally distant or ambient vocal may need continuous space. In that case, use level, pre-delay, filtering, and ducking to retain intelligibility.
