# Using Auto Filter Notch for Sound Design

Type: Creative technique
Tags: Mixing, Sound design workflow
Status: Approved
Reviewed: 2026-07-01

Short answer:
Auto filter notches are a powerful tool in sound design that can be used to create unique effects and variations within tracks.

Try this:
1. Mute the auto filter for specific elements (e.g., kick, snare) as needed.
2. Delete drums or bass parts for certain beats to add subtle gaps.
3. Use the same technique with other instruments like guitar or piano to enhance their presence without overpowering the main track.
4. Experiment with different notches and frequencies to achieve desired tonal changes.

Why it matters:
This method allows producers to subtly alter the mix by removing or modifying elements, creating a richer and more dynamic sound that can be easily replicated in future projects.

Common mistakes:
- Overusing auto filter notches can lead to an overly processed sound.
- Not enough experimentation with different frequencies might result in unnoticeable changes.
