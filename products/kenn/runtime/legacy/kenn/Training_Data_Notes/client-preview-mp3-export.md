# Client Preview MP3 Export

Type: Delivery workflow
Tags: export, mp3, client, preview, delivery, bounce, wav, mix, revision
Status: Approved

Short answer:
Send MP3s only as client previews, not as the final approved mix format. Export the main mix as WAV or AIFF, then create a clearly named MP3 preview for quick listening, feedback, or phone checks.

Try this:
1. Bounce the approved mix range first and listen to the exported file from disk.
2. Keep the final delivery as WAV or AIFF unless the client specifically asks otherwise.
3. Create an MP3 preview for fast review, clearly named as a preview or revision.
4. Use consistent names such as Artist_Song_MIX_v2_preview.mp3 and Artist_Song_MIX_v2.wav.
5. Do not let the preview limiter or loudness setting hide mix problems that need fixing.
6. Include a short note explaining which file is final quality and which is for preview only.

Why it matters:
MP3 previews are convenient, but clients can confuse them with final masters. Clear naming and a proper WAV or AIFF delivery avoids avoidable revision emails and wrong-file approvals.
