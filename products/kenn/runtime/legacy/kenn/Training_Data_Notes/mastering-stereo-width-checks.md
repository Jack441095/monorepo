# Mastering Stereo Width Checks

Type: Mastering workflow
Tags: mastering, stereo width, mono, phase, correlation, translation, mid-side, monitoring
Status: Approved

Short answer:
Be conservative with stereo widening in mastering. Check mono, correlation, low-end centre focus, and vocal/snare stability before approving any width move. Widening should feel like polish, not like the mix falls apart when summed.

Try this:
1. Leave sub bass, kick weight, lead vocal, snare, and core groove solid in the centre.
2. Use mid-side EQ or a width tool gently on upper ambience, air, or side information only.
3. Check mono after every width change; the vocal and low end should not disappear.
4. Watch correlation or phase meters, but trust the mono playback check first.
5. Compare on headphones and small speakers because exaggerated sides can feel impressive but translate badly.
6. If the master gets hollow, narrow the sides or fix width inside the mix instead.

Why it matters:
Mastering width affects the whole record at once. A small width lift can open a mix, but over-widening creates phase issues, weak centres, and poor translation on phones, clubs, and mono playback.
