# Ableton Echo Device

Type: Ableton device workflow
Tags: ableton, echo, delay, ping pong, mid side, modulation, feedback, noise, character, filter, reverb
Status: Approved
Source: Ableton Live 12 Reference Manual (live12-manual-en.pdf)
Reviewed: 2026-07-06

Short answer:
Echo is an advanced modulation and delay processor that combines digital control with vintage analog character. It supports Stereo, Ping Pong, and Mid-Side delay modes, features a dedicated feedback loop, integrated LFO modulation, dual filters, and an analog-style Character section (noise and wobble).

Try this:
1. Insert Echo on a Return track and set Dry/Wet to 100% for parallel delay processing.
2. Select a channel mode in the center panel: Stereo (independent Left/Right times), Ping Pong (bounces feedback between Left and Right), or Mid-Side (Mid channel centered, Side channel wide).
3. Sync the delay times to the song tempo (e.g., 1/8D or 1/4) or set them in milliseconds for free-running delays.
4. Set the Feedback parameter: set higher values for long feedback loops, and use the built-in Feedback Filter (lowpass/highpass) to roll off low-end mud and high-end harshness.
5. Open the Modulation tab to route the LFO or Envelope follower to the delay time or filter cutoff, generating tape-flutter chorus, pitch wobbles, or dynamic sweeps.
6. Open the Character tab and adjust the Noise (adds analog tape hiss) and Wobble (adds tape speed fluctuations/pitch instability) parameters to color the sound.
7. Increase the Reverb parameter to route the feedback path through an integrated algorithmic reverb, adding space directly within the delay tail.

Why it matters:
Echo is a highly creative and versatile delay device. Its Mid-Side mode allows you to keep vocal delays clear and wide, while its Wobble and Feedback filters let you build dub delays and warm, analog-sounding tails with ease.

Common mistakes:
- Leaving the default Character Noise setting too high, which can build up dynamic hiss and noise floor mud across multiple channels.
- Stacking excessive feedback with no highpass filtering, which can cause the delay loop to run away and clip the master bus.

When this does not apply:
- Basic utility delays (like Simple Delay or Channel Delay) where low CPU usage is the priority.
