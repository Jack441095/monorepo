# Bass Processing Basics

Type: Production workflow
Tags: bass, sub, low-end, saturation, sidechain, eq, mixing
Status: Approved

Short answer:
Process bass in stages: control the low end with EQ, add movement with gentle saturation, then make space with sidechain compression from the kick so the sub stays clear on small speakers.

Try this:
1. High-pass non-bass elements that do not need sub information so the low end stays clean.
2. On the bass track, use EQ Eight to cut muddy low-mids (around 200–350 Hz) only if the bass sounds boxy, not by default.
3. Add Saturator or Pedal on a send or the bass group for harmonics so the bass is audible on laptop speakers.
4. Sidechain compress the bass to the kick (short attack, medium release) so the kick punches through.
5. Level the bass against the kick in mono-check; the sub should feel steady, not louder than the kick unless the genre needs it.

Why it matters:
Bass processing is less about one magic plugin and more about separation, harmonics, and headroom. A focused note stops the chatbot from confusing general drum or stem-separation manual pages with actual bass workflow advice.
