# Using the Inverse Principle for Stereo Width

Type: Sound design workflow
Tags: stereo width, inverse principle, bass placement, drum stereo
Status: Approved
Reviewed: 2026-07-01

Short answer:
By applying the inverse principle to drums and bass, you can create a wide stereo image while keeping the transients of the bass in the side channels.

Try this:
1. Apply the inverse principle to all drums and base instruments.
2. Set the mid signal for the bass at 50% gain.
3. Use EQ to boost the high frequencies around 4kHz, creating a wider stereo width without losing clarity.
4. Keep the transients of the drums mono.

Why it matters:
This technique allows you to maintain the core elements (like the bass) in the side channels while expanding the overall mix width, enhancing the stereo imaging and making the synth stand out more prominently.

Common mistakes:
- Not properly balancing the transients between mono and stereo.
- Overusing the inverse principle, which can lead to a harsh or unnatural sound if not done correctly.
