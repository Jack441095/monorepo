# Creating Presets for Reusable Sounds

Type: Mixing technique
Tags: Ableton Live, Production workflow, Sound design
Status: Approved
Reviewed: 2026-07-01

Short answer:
By creating presets from your favorite sounds and instruments, you can save time and ensure consistency across different projects.

Try this:
1. Create a new folder in your user library named "slam" for easy organization.
2. Name the track "Serum 2" and add it to the "slam" folder.
3. Drag all relevant tracks from the current project into the "slam" folder, including the preset, effects, and MIDI settings.
4. Save the new track as a preset in your user library.

Why it matters:
This technique allows you to quickly access and reuse sounds without having to recreate them every time, saving both time and effort.

Common mistakes:
- Not naming the presets clearly or using consistent naming conventions can make it difficult to find specific tracks.
- Saving too many presets can clutter your library and make organization harder.
