# Drum Rack Basics

Type: Beginner explanation
Tags: drum rack, drums, pads, samples, midi
Status: Approved

Short answer:
Drum Rack lets you place drum samples or instruments on pads and play them with MIDI notes.

Try this:
1. Add a Drum Rack to a MIDI track.
2. Drag a kick, snare, hat, or percussion sample onto a pad.
3. Create a MIDI clip and draw notes for each pad.
4. Adjust each pad's volume so the kit balances before adding effects.
5. Group similar sounds or use return chains for shared reverb or delay.

Why it matters:
Drum Rack keeps individual drum sounds organized while letting you process each sound separately.
