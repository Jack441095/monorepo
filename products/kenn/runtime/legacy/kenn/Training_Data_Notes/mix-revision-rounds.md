# Mix Revision Rounds

Type: Client workflow
Tags: mixing, revision, client, feedback, stems, delivery, workflow
Status: Approved

Short answer:
Treat revisions as a scoped round: confirm what changed (new stems vs mix tweaks), limit the number of passes in the quote, and bounce a labeled revision so the client hears exactly what you adjusted.

Try this:
1. Ask the client to list changes in writing (e.g. “vocals +1 dB, less reverb on chorus, kick punchier”) instead of only “make it better.”
2. Duplicate the pre-revision mix project or save a new Set name with the revision number (`Song_v2_mix`).
3. Change only what was agreed; avoid rebuilding the whole mix unless new stems were supplied.
4. A/B the revision against the previous bounce on the same speakers/headphones you used for the first pass.
5. Export `Artist_Song_mix_v2.wav` (and optional instrumental) at the same sample rate as the first delivery.
6. Send a short note: what you changed, what is still flexible, and whether another round is included.

Why it matters:
Revision chaos is the main cause of unpaid extra hours. A clear Ableton workflow plus written scope keeps mixes profitable and clients confident.
