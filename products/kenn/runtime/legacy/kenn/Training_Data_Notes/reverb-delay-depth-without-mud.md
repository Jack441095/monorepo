# Reverb Delay Depth Without Mud

Type: Mixing workflow
Tags: reverb, delay, sends, depth, mud, vocals, mixing
Status: Approved

Short answer:
Create depth with sends, pre-delay, EQ, and automation. Keep low-end and low-mid buildup out of reverbs and delays so the mix feels spacious without becoming cloudy.

Try this:
1. Put reverb and delay on return tracks so several sounds can share the same space.
2. High-pass the reverb return to remove unnecessary low-end rumble.
3. Cut some low mids on the reverb return if the mix becomes boxy or cloudy.
4. Use pre-delay on vocal reverbs so the dry vocal stays upfront.
5. Use delay throws on selected words or fills instead of leaving delay loud all the time.
6. Automate send levels between sections so space changes with the arrangement.

Why it matters:
Space is a mix decision, not just an effect. Controlled ambience can make a track feel expensive; uncontrolled ambience hides timing, lyrics, drums, and low-end clarity.
