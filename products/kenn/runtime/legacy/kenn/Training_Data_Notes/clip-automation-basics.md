# Clip Automation Basics

Type: Production workflow
Tags: automation, clip, envelope, modulation, arrangement, workflow, ableton
Status: Approved

Short answer:
In Arrangement View, draw automation on clip lanes or under tracks; in Session View, use clip envelopes on MIDI or audio clips for parameter changes that stay with the loop.

Try this:
1. Show automation: right-click a track → Show Automation, or press A in Arrangement View.
2. Choose the parameter (volume, device macros, send level) from the automation chooser.
3. Draw breakpoints with the pencil tool; use stepped lines for on/off switches.
4. On Session clips: open the clip → Envelopes tab → pick a device parameter and draw the envelope.
5. Copy automation between clips by duplicating the clip or using copy/paste on the envelope lane.

Why it matters:
Clip envelopes move with the musical idea; track automation is better for global mix rides. Picking the right container keeps edits reversible and organised.
