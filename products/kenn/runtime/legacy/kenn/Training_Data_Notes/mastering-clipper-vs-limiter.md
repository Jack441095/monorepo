# Mastering Clipper Vs Limiter

Type: Mastering workflow
Tags: mastering, clipper, limiter, loudness, true peak, transients, headroom, final
Status: Approved

Short answer:
Use a clipper to shave fast transient peaks before the final limiter, then use the limiter for final loudness and true-peak control. If the clipper changes the punch or makes cymbals gritty, back it off and let the limiter do less dramatic work.

Try this:
1. Put corrective EQ and broad tone shaping before loudness processing.
2. Add a clipper before the limiter only if short peaks are making the limiter work too hard.
3. Clip gently; listen for kick click, snare crack, vocal edge, and cymbal grit.
4. Put the final limiter last and set output ceiling or true-peak ceiling for the delivery target.
5. Compare loudness-matched bypasses so louder does not trick you into approving distortion.
6. If the mix loses depth or punch, reduce clipping first, then limiter gain.

Why it matters:
A limiter can flatten the whole master when it has to catch every transient. Gentle clipping can make loudness easier, but heavy clipping turns into audible distortion and can make the master smaller.
