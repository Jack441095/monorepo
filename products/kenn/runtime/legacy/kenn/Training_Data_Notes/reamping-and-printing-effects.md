# Reamping and Printing Creative Effects

Type: Production workflow
Tags: reamping, resampling, printing, effects, routing, latency, creative workflow
Status: Approved
Source: Audio_Too studio practice
Reviewed: 2026-07-01

Short answer:
Record creative processing to a new audio track while preserving the clean source. Print several intentional passes, then edit the best moments instead of leaving an unstable real-time chain to decide the result later.

Try this:
1. Duplicate or preserve the dry source and label it clearly before recording processed audio.
2. Route the source to a dedicated audio track, avoid feedback paths, and monitor the return at a safe level.
3. Record full-length passes while performing effect parameters, pedals, or outboard controls.
4. Check latency alignment and polarity against the dry signal before blending them in parallel.
5. Consolidate selected moments, add short fades, and document external hardware settings that cannot be recalled automatically.

Why it matters:
Printing commits a repeatable sound, reduces CPU load, and turns live effect performance into editable arrangement material while the preserved dry track keeps the decision reversible.
