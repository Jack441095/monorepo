# Ableton Looper Device

Type: Performance workflow
Tags: looper, loop, overdub, record, ableton, live performance, layering, sync, tempo
Status: Approved
Source: Ableton Live 12 Manual
Reviewed: 2026-07-01

Short answer:
Looper is a real-time audio loop recorder that records, overdubs, and plays back in a single device. It can sync to Live's tempo automatically or run free at its own length. The transport states — Record, Overdub, Play, Stop — cycle with a single footswitch-friendly button, making it ideal for live looping without a mouse.

Try this:
1. Drop Looper on an audio or return track after your input chain.
2. Press the main button once to start recording. Press again to stop recording and immediately start playback.
3. Press again to Overdub — new audio layers onto the existing loop. Press to return to Play without adding more.
4. Set Sync to On so the loop snaps to the nearest bar length relative to Live's transport. This keeps loops in time without counting bars manually.
5. Set Quantization in Looper to 1 or 2 bars — recording starts and ends on a bar boundary regardless of when you press the button.
6. Speed controls pitch and time together (like tape). Use -1 OCT for a down-octave effect. Speed 0 stutters.
7. To clear: hold the main button or double-tap depending on your mapping. The loop resets to empty.
8. Map the main button to a MIDI footswitch for hands-free control. Use MIDI Map mode (Cmd+M) to assign.

Why it matters:
Looper turns a single track into a multi-layer live performance instrument. With sync on, loops stay locked to Live's grid — useful for building up live arrangements in real time.

Common mistakes:
- Recording without Sync on and ending up with a loop that drifts from the grid.
- Overdubbing when you meant to Play — the state order is Record → Overdub → Play, not Record → Play.
- Not setting input monitoring correctly — Looper records what reaches it in the chain, so make sure your effects are before Looper if you want them printed.

When this does not apply:
For studio layering and comping, Session View clip recording is cleaner. Looper is for live performance and sketch recording.
