# Warp Markers

Type: Beginner explanation
Tags: warping, warp markers, timing, audio clips
Status: Approved

Short answer:
Warp markers lock points in an audio clip to points on Ableton's timeline. They are useful for tightening timing, fixing drifting loops, and reshaping rhythm.

Try this:
1. Double-click an audio clip to open Clip View.
2. Turn Warp on if it is not already enabled.
3. Find a clear transient, such as a kick, snare, vocal start, or guitar strum.
4. Double-click above the waveform to create a warp marker.
5. Drag the marker so that transient lines up with the grid.
6. Add another marker later in the clip if the timing drifts.

Why it matters:
Warp markers let you fix timing without slicing or re-recording. Use fewer markers for natural audio, and more markers for tight rhythmic edits.
