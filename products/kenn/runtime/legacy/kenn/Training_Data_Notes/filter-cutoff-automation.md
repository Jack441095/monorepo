# Filter Cutoff Automation

Type: Ableton workflow
Tags: ableton, automation, filter, cutoff, auto filter, device parameter, envelope, modulation
Status: Approved

Short answer:
Automate filter cutoff by placing Auto Filter or another filter device on the track, showing automation lanes, then choosing the device's Frequency or Cutoff parameter. Draw a smooth sweep for build-ups, stepped moves for rhythmic gating, or clip envelopes when the movement should stay inside a loop.

Try this:
1. Add Auto Filter to the audio, MIDI, group, or return track you want to move.
2. Press A in Arrangement View to show automation lanes.
3. Open the automation chooser and select Auto Filter Frequency or the filter device's Cutoff parameter.
4. Draw two or more breakpoints for a sweep, or use the pencil tool for stepped rhythmic movement.
5. Keep resonance moderate while writing the move so the sweep does not jump out painfully.
6. If the automation belongs to a repeating loop, put it in the clip envelope instead of the track lane.

Why it matters:
Cutoff automation is a musical movement tool, not just an effect. Keeping it on the right lane or clip makes the sweep repeatable, editable, and easy to bypass while comparing the dry part.
