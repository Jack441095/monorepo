# Prepare A Session For Mixing

Type: Production workflow
Tags: mixing, session, organization, groups, routing, workflow, prep
Status: Approved

Short answer:
Before touching EQ or compression, fix structure: group tracks, name and color consistently, delete muted junk, and set rough static balances so mixing decisions are about tone and space, not finding clips.

Try this:
1. Rename tracks clearly (`VOX_LEAD`, `DRUMS_BUS`, `BASS_SUB`, `GTR_RHY`).
2. Group drums, bass, music, vocals, and FX; route all groups to a **MIX** bus (see group-bus-workflow note).
3. Remove unused takes, deactivated clips, and duplicate plugins that CPU-clone the same idea.
4. Set rough fader balances and panning with plugins bypassed on mix buses.
5. Mark song sections with locators (Intro, Verse, Chorus) for automation later.
6. Save `SongName_MIX_v1.als` before adding mix-bus compression or reverbs.
7. Confirm sample rate and bit depth match the client’s delivered stems.

Why it matters:
Most “mix problems” at Audio_Too are session clutter and unclear routing. Prep notes train the chatbot to answer “where do I start?” without dumping manual page noise.
