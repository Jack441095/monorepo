# Sidechain Bass To Kick

Type: Production workflow
Tags: sidechain, bass, kick, compression, mixing, low-end, pumping, attack, release, tempo, threshold, gain-reduction
Status: Approved

Short answer:
Use a compressor on the bass (or bass bus) with the kick as the sidechain input so the bass ducks when the kick hits. Short attack and a release that breathes with the tempo keeps the sub clear without obvious pumping.

Try this:
1. Group bass layers to a bus if you have sub + mid bass tracks.
2. Add Compressor to the bass bus; enable Sidechain, choose the kick track as the external source.
3. Start around 4:1 ratio, attack 0–5 ms, release 80–150 ms (adjust by ear and genre).
4. Lower threshold until you see 2–6 dB gain reduction on kick hits only.
5. Check in mono: kick should stay upfront, bass should recover quickly between hits.

Why it matters:
Kick/bass masking is the most common low-end problem clients describe. This note gives retrieval a direct workflow instead of generic compression manual text.
