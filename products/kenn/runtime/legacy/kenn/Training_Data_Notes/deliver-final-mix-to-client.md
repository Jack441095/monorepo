# Deliver Final Mix To Client

Type: Client workflow
Tags: delivery, client, bounce, export, mixing, mastering, files, workflow
Status: Approved

Short answer:
Deliver one primary approved mix format plus clear filenames and a short cover note. Include sample rate, bit depth, and what versions exist (main, instrumental, TV mix) so the client does not open the wrong file.

Try this:
1. Confirm delivery spec in email: WAV/AIFF, 24-bit, 44.1 or 48 kHz, stereo interleaved.
2. Remove reference tracks and mute buses not meant for export; disable master limiter if sending “mix” not “master.”
3. Bounce from the start marker through the end of the song; include 0.5–1 s tail after the fade.
4. Name `Artist_Song_MIX_v1.wav` (and `Artist_Song_INST_v1.wav` if contracted).
5. Listen to the bounced file from disk — not only from Live — before sending.
6. Zip if multiple files; upload with a link that does not expire in 24 hours without warning.
7. Email template: files included, approved version number, what revisions cover, and how loudness compares to their reference (if discussed).

Why it matters:
Professional delivery reduces “which file is final?” emails and supports Audio_Too’s mixing and mastering reputation.
