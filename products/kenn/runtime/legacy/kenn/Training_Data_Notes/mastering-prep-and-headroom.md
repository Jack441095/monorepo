# Mastering Prep And Headroom

Type: Mastering workflow
Tags: mastering, headroom, export, limiter, loudness, mixdown
Status: Approved

Short answer:
Prepare a mix for mastering by exporting a clean stereo file with no clipping, no limiter used only for loudness, and enough headroom for processing. The mix should already sound balanced before mastering starts.

Try this:
1. Remove any master limiter that is only there to make the mix louder.
2. Leave creative mix bus processing on if it is part of the sound, but avoid clipping the output.
3. Aim for peaks below 0 dBFS; around -6 dB peak headroom is a practical target, not a strict rule.
4. Export at the project sample rate and use 24-bit WAV or 32-bit float WAV.
5. Include a reference track and notes about the desired loudness, tone, and platform if relevant.
6. Check the exported file from start to finish before sending it.

Why it matters:
Mastering cannot reliably fix a distorted, clipped, or unbalanced mix. Good prep gives the mastering stage room to enhance tone, translation, sequencing, and loudness.
