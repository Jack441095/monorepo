# Expander and Gate Noise Control

Type: Mixing technique
Tags: gate, expander, downward expansion, natural noise reduction, steady background noise, threshold, drums, vocals, dynamics
Status: Approved
Source: Audio_Too studio practice
Reviewed: 2026-07-01

Short answer:
Use an expander for natural noise reduction and a gate when deliberate on/off separation is required. Set the threshold from the quietest wanted performance, not from the noise alone.

Try this:
1. Listen to the quietest wanted notes and set the threshold below their stable level.
2. Start with gentle downward expansion and limited range before using a fully closed gate.
3. Use enough attack to keep transients, enough hold to prevent chatter, and a release that follows the source's decay.
4. Filter the detector when kick, cymbal spill, or low-frequency rumble triggers the processor incorrectly.
5. Print or automate edits when a gate repeatedly cuts words, breaths, or drum tails.

Why it matters:
Aggressive gating replaces steady noise with distracting openings and closures. Expansion can improve separation while preserving the performance's natural envelope.
