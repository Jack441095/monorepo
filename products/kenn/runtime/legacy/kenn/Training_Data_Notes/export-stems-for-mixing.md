# Export Stems For Mixing

Type: Production workflow
Tags: export, stems, bounce, mixing, delivery, workflow
Status: Approved

Short answer:
Freeze or consolidate tracks, disable master limiting, export 24-bit WAV at the session sample rate, and label stems clearly. Include a rough mix reference if the client is sending material to you.

Try this:
1. Remove or bypass limiters on the master before export unless the client wants a mastered reference.
2. Solo each stem group (drums bus, bass, vocals, etc.) or use Export → Selected Tracks Only.
3. Export WAV, 24 bit, project sample rate (44.1 or 48 kHz); keep all stems the same length.
4. Name files with project name and element: `Artist_Song_drums.wav`.
5. Zip stems plus a short text file listing BPM, key, and notes about tuning or issues.

Why it matters:
Stem export questions are business-critical for Audio_Too. Clear steps reduce back-and-forth and match how you actually deliver work.
