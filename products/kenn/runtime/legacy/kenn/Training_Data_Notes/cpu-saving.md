# Reducing CPU Load

Type: Troubleshooting
Tags: cpu, freeze, buffer, latency, performance, plugins
Status: Approved

Short answer:
If Ableton is glitching or crackling, reduce the processing load or increase the audio buffer size.

Try this:
1. Freeze heavy instrument or effects tracks.
2. Bounce committed parts to audio.
3. Turn off unused devices and tracks.
4. Increase the audio buffer size while mixing.
5. Use lower oversampling or high-quality modes until final export.
6. Close other apps that are using CPU or memory.

Why it matters:
Low latency settings are useful for recording, but mixing usually works better with a larger buffer and fewer live devices.
