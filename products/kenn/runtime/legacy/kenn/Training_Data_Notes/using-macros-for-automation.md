# Using Macros for Automation

Type: Mixing technique
Tags: Macro automation, LFOs, FM synthesis, Native Instruments Reactor Scravel
Status: Approved
Reviewed: 2026-07-01

Short answer:
By attaching different parameters to macros in Ableton Live, you can quickly create variations of lasers and other effects. This technique allows for experimentation with envelope length, D-tune, wavet position, effect choice, and resonance/cut frequency.

Try this:
1. Attach the envelope length parameter to a macro.
2. Attach the D-tune parameter to a macro.
3. Attach the wavet position parameter to a macro.
4. Attach the effects choice parameter to a macro.
5. Attach the resonance/cut frequency parameters to macros.

Why it matters:
This technique enables producers to quickly create and experiment with various laser-like effects, such as lasers, symbols, crashes, and other spectral elements. It can be used in both mixing and performance contexts for cinematic or horror movie soundscapes.

Common mistakes:
- Not understanding the relationship between macro parameters and effect variations.
- Overthinking the automation process, leading to excessive complexity without clear benefits.
