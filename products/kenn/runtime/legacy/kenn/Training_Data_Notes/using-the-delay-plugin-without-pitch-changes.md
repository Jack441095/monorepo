# Using the Delay Plugin Without Pitch Changes

Type: Sound design workflow
Tags: Ableton Live, delay plugins, pitch manipulation, time stretching, glitch effects
Status: Approved
Reviewed: 2026-07-01

Short answer:
The ability to use Ableton's delay plugin without changing pitch can create unique and interesting sound designs. By setting the mode from "Repitch" to "Fade," you eliminate pitch changes but introduce time stretching, which can be used for glitchy effects.

Try this:
1. Set up a basic delay in Ableton.
2. Change the delay time slowly while monitoring the audio.
3. Adjust the modulation rate of the delay plugin to control the speed and intensity of the effect.
4. Experiment with different modes (e.g., "Ping Pong," "Jump Mode") for varied results.

Why it matters:
This technique allows producers to create glitchy, tape-stopped effects without altering pitch, adding a fresh dimension to their sound design toolkit.

Common mistakes:
- Not understanding that changing the mode from "Repitch" to "Fade" eliminates pitch changes.
- Forgetting to adjust the modulation rate for consistent effect intensity.
