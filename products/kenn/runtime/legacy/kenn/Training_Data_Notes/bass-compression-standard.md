# Bass Compression (Standard, Not Sidechained)

Type: Production workflow
Tags: bass, sub, compression, compressor, dynamics, ratio, attack, release, mixing
Status: Approved

Short answer:
Compressing a bass track on its own (not keyed from the kick) is about consistency, not ducking -- even out an inconsistent performance, keep the low end from jumping around in level, and add sustain or punch depending on the attack setting.

Try this:
1. Start with a moderate ratio (3:1 to 5:1) -- bass usually needs firmer control than a vocal, but not the aggressive 8:1+ ratios used for parallel/limiting duty.
2. Set the attack based on what you want to keep: slower attack (10-30 ms) lets the pick/pluck transient through for definition; faster attack (0-5 ms) tames the transient for a smoother, more consistent tone.
3. Set the release so gain reduction recovers before the next note -- too slow and the compressor "pumps" or dulls the following notes; use auto-release if the part's rhythm varies a lot.
4. Set the threshold for 3-6 dB of gain reduction on the loudest notes only -- more than that starts flattening the natural dynamics between notes.
5. Check level-matched (bypass vs compressed at the same loudness) -- the goal is a more consistent, controlled bass, not just "louder."

Why it matters:
This is a different job from sidechain compression (see sidechain-bass-to-kick.md), which ducks the bass against the kick for rhythmic space. Standard compression here controls the bass's own dynamics -- an inconsistent take, string-to-string level differences, or a part that needs to sit more evenly in the mix. Both techniques are often used together: standard compression first to even out the performance, sidechain second (or a separate compressor) to carve space against the kick.

Common mistakes:
- Reaching for a fast attack by default -- it kills the pluck/pick transient that gives bass its definition and audibility on small speakers.
- Compressing so hard the natural note-to-note dynamics disappear, leaving a flat, lifeless bass line.
- Confusing this with sidechain compression when the actual problem is kick/bass masking, not an inconsistent bass performance -- if the symptom is "bass disappears when the kick hits," that's a sidechain problem, not a standard-compression one.
