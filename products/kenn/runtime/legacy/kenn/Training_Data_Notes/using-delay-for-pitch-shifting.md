# Using Delay for Pitch Shifting

Type: Mixing technique
Tags: delay, pitch shifting, glitching
Status: Approved
Reviewed: 2026-07-01

Short answer:
To achieve pitch shifting with a delay effect in Ableton Live, simply set the delay time to move up or down the frequency. This can create interesting effects like glitchy time stretching.

Try this:
1. Create a new chain.
2. Add an echo and other effects on the delayed track.
3. Increase the delay time slightly for more pitch shifting.
4. Experiment with different modulation rates using internal modulation.

Why it matters:
This technique allows producers to manipulate pitch without traditional EQ or reverb, adding a unique sonic texture that can be both creative and challenging.

Common mistakes:
- Not understanding how to use the delay effect's parameters correctly.
- Not experimenting enough with different delay times and modulations for varied effects.
