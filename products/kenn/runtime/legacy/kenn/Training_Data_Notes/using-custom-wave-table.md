# Using Custom Wave Table

Type: Mixing technique  
Tags: Sound design workflow, Recording workflow  
Status: Approved  
Reviewed: 2026-07-01  

Short answer:
Custom wave tables can be used to create complex and varied soundscapes by blending different frames from various wavetables.

Try this:
1. Import a glitchy sample with varying brightnesses.
2. Use the formula parser in Ableton Live's edit window to set frame size at 2,000 samples for better visualization of each wave table frame.
3. Split the sample into multiple frames using the formula parser.
4. Delete unnecessary frames and keep only those that offer variety.

Why it matters:
Custom wave tables can significantly enhance the depth and complexity of your sound design by providing a rich palette of textures and harmonics, making your tracks more interesting and engaging for listeners.

Common mistakes:
- Not choosing samples with enough variation in brightness.
- Using too small a frame size (e.g., 200) which results in low-quality audio.
