# Reference Track Level Matching

Type: Mixing workflow
Tags: reference, mixing, level, balance, ab, comparison, workflow
Status: Approved

Short answer:
Use a reference for tone and balance, not as a loudness contest: level-match the reference to your mix, switch quickly, and note one or two differences per pass instead of chasing the reference’s master limiter.

Try this:
1. Import the reference onto an audio track; route it only to your ears (not to the mix bus).
2. Put Utility Gain on the reference track; lower it until chorus energy feels similar to your mix, not until meters match numerically.
3. Loop the same section (e.g. chorus) on both mix and reference.
4. Write three observations: low end, vocal presence, width/space — fix one category per pass.
5. Bypass reference processing on your mix bus while comparing (reference is already mastered).
6. Remove or mute the reference before the final bounce so it is never exported by mistake.

Why it matters:
Clients often send a “sounds like this” track. Level-matched A/B avoids turning mixes into over-limited copies and gives the chatbot a sane reference workflow.
