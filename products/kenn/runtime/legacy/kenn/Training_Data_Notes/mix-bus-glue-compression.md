# Mix Bus Glue Compression

Type: Mixing workflow
Tags: mixing, glue compressor, bus, compression, dynamics, workflow
Status: Approved

Short answer:
Mix-bus glue holds the mix together with gentle compression — usually 1–3 dB gain reduction on peaks. Set rough balances first; add glue after most channel processing so you are not fighting an early squash.

Try this:
1. Route groups to a **MIX** bus; leave the master fader at 0 dB with headroom.
2. Insert Glue Compressor on the MIX bus (or Light bus comp if Glue is too colored for the genre).
3. Start ratio 2:1, attack 10–30 ms, release auto or 0.4 s; soft knee if available.
4. Adjust threshold until gain reduction peaks around 1–3 dB on loud sections only.
5. Bypass and compare at matched level (Utility after comp trim) — glue should add cohesion, not obvious pumping.
6. Avoid stacking another heavy limiter on the mix bus before mastering; save limiting for the master stage.
7. If the mix feels dull, reduce bus compression before boosting highs on every track.

Why it matters:
Clients ask about “glue” and punch in the same breath. This note gives the chatbot a bus-focused answer distinct from channel compression or mastering.
