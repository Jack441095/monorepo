# Reverb Send Workflow

Type: Production workflow
Tags: reverb, delay, sends, returns, mixing, space
Status: Approved

Short answer:
Use return tracks for reverb and delay instead of long reverbs on every channel. EQ the return, set send levels per sound, and keep the dry mix in charge of clarity.

Try this:
1. Create a Return track with Reverb; set Dry/Wet to 100% wet on the return.
2. High-pass the return around 200–400 Hz so the low end stays tight.
3. Send vocals, snares, or synths to the return with low send amounts (start ~10–20%).
4. Add a second return for short plate or room if you need contrast; avoid stacking three reverbs on one sound.
5. Automate send levels for builds instead of cranking return fader globally.

Why it matters:
Clients often muddy mixes by inserting reverbs on every track. A send-based workflow note steers answers toward professional balance.
