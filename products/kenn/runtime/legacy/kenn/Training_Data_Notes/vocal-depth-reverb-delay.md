# Vocal Depth With Reverb And Delay

Type: Mixing workflow
Tags: vocals, depth, reverb, delay, pre-delay, sends, throws, space, front, back, mixing
Status: Approved

Short answer:
Use pre-delay, short ambience, and controlled delay throws to create vocal depth without pushing the vocal behind the beat. Keep the dry vocal upfront, then automate sends so only selected words or sections move deeper.

Try this:
1. Set the dry vocal level first; depth will not fix a vocal that is too quiet.
2. Put reverb and delay on sends so you can EQ and automate them separately.
3. Use pre-delay on vocal reverb so consonants stay clear and upfront.
4. High-pass and low-pass the reverb return so it supports the vocal without adding mud or hiss.
5. Use delay throws on phrase endings instead of constant loud delay.
6. Automate send levels: dryer for dense verses, wider/deeper for hooks and transitions.

Why it matters:
Depth is a balance between clarity and space. Too much constant ambience makes lyrics blurry; controlled sends make the vocal feel placed in a real mix.
