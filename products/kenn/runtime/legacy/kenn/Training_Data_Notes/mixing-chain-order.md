# Mixing Chain Order

Type: Production workflow
Tags: mixing, eq, compression, saturation, effects, workflow
Status: Approved

Short answer:
A practical order is: balance levels → corrective EQ → dynamics (compression) → tone (saturation / color) → spatial effects (reverb / delay) → automation. Adjust for taste, but fix problems before you add character.

Try this:
1. Set rough fader balances and panning with EQ bypassed so you hear level relationships first.
2. Use EQ Eight to remove problems (mud, harshness) before adding excitement.
3. Add Glue Compressor or a light channel compressor to control dynamics, not to “fix” a badly balanced fader.
4. Add saturation or parallel distortion after dynamics so you are coloring a controlled signal.
5. Send to reverbs and delays on return tracks; high-pass or EQ those returns so the mix stays clear.
6. Automate sends and filter sweeps last when the static mix already works.

Why it matters:
“What order should I mix in?” is a common client question. This note keeps retrieval focused on workflow, not random device documentation.
