# Drum Parallel Compression

Type: Mixing workflow
Tags: drums, parallel compression, compression, punch, bus, mixing
Status: Approved

Short answer:
Parallel compression adds density and excitement by blending a heavily compressed drum signal underneath the dry drums. Keep the dry drums punchy and use the compressed return for sustain and attitude.

Try this:
1. Create a drum bus or return track and send the drum group to it.
2. Add a compressor with a strong ratio and lower threshold until the return sounds obviously compressed.
3. Use medium attack if you want transients to pass, or fast attack if you want more smashed character.
4. Blend the parallel track quietly under the dry drums.
5. High-pass or EQ the parallel return if kick low-end becomes too heavy.
6. Bypass the return often; the mix should feel more energetic, not simply louder.

Why it matters:
Parallel compression is useful when drums need body without flattening the main transient. It is especially helpful for dense electronic, rock, and pop productions.
