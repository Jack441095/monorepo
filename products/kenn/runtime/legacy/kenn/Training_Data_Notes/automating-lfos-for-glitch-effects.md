# Automating LFOs for Glitch Effects

Type: Mixing technique  
Tags: Automation, LFO, Chaos, Glitch  
Status: Approved  
Reviewed: 2026-07-01

Short answer:
Automate the rate and depth of your LFO to create a chaotic modulation effect that can be applied to various parameters in an effect chain.

Try this:
1. Create multiple instances of the LFO with different rates and depths.
2. Link these instances together to create a continuous, evolving pattern.
3. Assign one instance to each parameter you want to modulate (e.g., rate, depth) in your desired effect.
4. Automate the parameters to create smooth transitions between the different LFOs.

Why it matters:
This technique can add an unpredictable and dynamic quality to your tracks, adding a unique flavor of glitchy effects without relying on expensive plugins or complex setups. It's particularly useful for creating atmospheric textures or adding a sense of tension in electronic music productions.

Common mistakes:
- Not automating the LFO parameters properly, resulting in static modulation.
- Using only one LFO and not varying its speed and depth, leading to predictable results.
- Not combining multiple instances of different LFOs, which can limit the complexity and variety of your glitch effects.
