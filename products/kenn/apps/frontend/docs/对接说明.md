#  对接说明（速查）

## 要接哪些接口

| 做什么 | 方法 | 路径 |
|--------|------|------|
| 登录 | POST | `/api/auth/login`（可选；密码配在 `.env` 的 `VITE_MIX_REVIEW_DASHBOARD_PASSWORD`，界面无登录框） |
| 查是否已登录 | GET | `/api/auth/session` |
| 上传混音分析 | POST | `/api/mix-review` |
| 查分析进度 | GET | `/api/mix-review-status?id=xxx` |
| 拉完整报告（备用） | GET | `/api/mix-review-report/{id}.json` |

流程：上传 → 拿 `id` → 轮询状态 → 完成；缺数据再拉报告。

上传字段：`file`（必填）、`reference`（可选）、`title`、`version`、`mix_goal`、`reference_id`。

---

##  改了接口名，改哪里？

**只改一个文件：[`paths.ts`](../src/api/paths.ts)**

里面的 `API_PATHS` 就是全部 URL。业务代码不用动。

其它情况：

| 情况 | 改哪里 |
|------|--------|
| 前缀变成 `/api/admin` | `.env` 里 `VITE_MIX_REVIEW_API_PREFIX` |
| 换后端地址 | `.env` 里 `API_URL`（空则开发代理默认 `127.0.0.1:8090`） |
| Jack 要求 Dashboard 登录 | `.env` 里填 `VITE_MIX_REVIEW_DASHBOARD_PASSWORD`（界面无登录框，分析前自动登录） |
| 上传字段名变了 | `composables/useMixReview.ts` |
| 返回 JSON 字段变了 | `utils/mixReviewNormalize.ts` |
