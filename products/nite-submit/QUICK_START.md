# QUICK START — NITE Submit

1. **Open Submit**, or open a PDF with Submit from Finder.
2. **On first launch, enter your student number** if you want it reused when a
   PDF does not contain one. It is stored locally and can be cleared at any
   time.
3. **Drop your assignment PDF** onto the window (or click the drop zone to browse).
4. **Check the detected details.**
   - ✓ Found — high confidence, extracted from a clear label.
   - ? Check — plausible but please verify.
   - ! Missing — not found; type it in yourself.
   - Every field is editable. The app never invents a value.
   - If alternatives are detected, use that field's **Use…** menu to make an
     explicit choice; the choice remains subject to approval.
5. **Choose your naming rule** from the menu, or type your own template. The
   safe default is `{student_id}_{project_title}`; for a department that
   requires a module code, use `{student_id}_{module_code}_{project_title}`.
6. **Preview** shows the exact output filename as you type.
7. Click **Create Renamed Copy** (default, safest) — your original file is kept
   untouched. *Rename Original* changes only the name and can be undone.

If the PDF is scanned or image-only, the app tells you — just fill the fields in
manually and rename as normal.

Everything happens on your Mac. Nothing is uploaded.
