# SLO — Sample Library Optimiser

SLO is the single canonical product formerly called Smart Sample Manager. Historical reports, branches, receipts, and source comments retain the former name where it is provenance.

The checkout contains the application, classification, evaluation, qualification, and research lineage. Worktrees live under `../../workspace/worktrees/slo/`.

Production classifier behaviour was not changed by this estate migration. The audio foundation-model probe remains research evidence only; no holdout was rerun.

## Which SLO document to trust

Read these first: `docs/ROADMAP_TO_BETA.md` (the plan, with an execution log), `SLO_BETA_BLOCKER_REGISTER_V2.md` (per-blocker evidence),
`SLO_PRIVATE_BETA_READINESS_V2.md` (the readiness verdict), and the 2026-09-18 evaluation set (`SLO_EVAL_PRIORITIES_2026-09-18.md`,
`SLO_FEATURE_ROADMAP_2026-09-18.md`). `SLO_BETA_EXECUTION_MASTER_PLAN_V1.md` is still the beta release process (signing, licensing, cohorts).

Everything else named `*_PLAN_*`, `*_ROADMAP_*` or `*_PROMPT_*` is a dated record. Those that nothing depended on were moved to
`docs/archive/`, `SmartSampleManager/docs/archive/` and `SmartSampleManager/docs/classification/archive/` on 2026-10-03.
Reports named `*_V1.md` are measurements from the date they were run; numbers in them may have been regenerated since.
