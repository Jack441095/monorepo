# SLO documentation

The public product name is **SLO (Sample Library Optimizer)**. The source directory,
download route, and catalog ID retain `SmartSampleManager` / `smart-sample-manager`
because existing builds, licences, and purchase metadata use those identifiers.

Current website, payment, hosting, and launch operations belong to the platform:

- [Operations audit and checklist](../../../../docs/OPERATIONS_AUDIT_2026-10-08.md)
- [Stripe commerce](../../../../docs/STRIPE_COMMERCE.md)
- [Commerce recovery runbook](../../../../backend/docs/COMMERCE_RUNBOOK.md)

The old Paddle/Railway deployment guides and duplicated platform phase plans
were removed on 2026-10-08. Git history retains them. Dated product validation
reports record their tested build; old provider names or references to retired
plans within them do not describe today's platform.

Product engineering evidence remains here: classification policy, acoustic
search, realtime safety, dependency bundling, licence verification, packaging,
and clean-machine procedures. A prior report passing does not approve a new
release. Public sales still require a registered artifact, signing/notarization
evidence where applicable, clean-machine acceptance, and customer delivery.
