# KENN Recommendation Quality

Detection and recommendation are not separated consistently in the current
Mix Review path: `review_flags()` feeds `priority_actions()` and advice. On
healthy controls it creates corrective framing from spectral, LRA, resonance,
and width heuristics. That is harmful advice in this benchmark because the
correct result is abstention.

Required recommendation schema: evidence kind (`MEASURED`, `DERIVED`,
`CLASSIFIER`, `REASONING`); scope (master/bus/track); time range; frequency
range; confidence provenance; alternative tests; trade-off; and an explicit
`no_material_issue` / `context_required` outcome.

Live provider behavioural qualification: **deferred**. No live-provider result
is fabricated.
