## Installed Python dependencies

Python dependencies are declared in `requirements.txt`,
`studio/kenn/kenn/requirements.txt`, and
`studio/audiogen/audiogen/pyproject.toml`. They are installed separately and
are not bundled as wheels in this archive. Each dependency remains subject to
the licence supplied by its publisher.

A hash-locked resolution and license manifest exist for this machine's main environment
(`requirements.lock.txt`, `requirements-dev.lock.txt`, `requirements-agents.lock.txt`, and
`docs/dependency_manifest.{json,md}`, generated by `scripts/generate_dependency_manifest.py`) —
see `docs/audits/2026-07-19-dependency-manifest.md` for what this does and does not yet cover
(notably: not yet regenerated on AudioGen's native environment or any other supported platform).

Before each release:

1. Resolve the dependency set independently for every supported platform (partial: see above).
2. Regenerate the software bill of materials with exact versions, artifact hashes,
   source locations, and detected licences (`scripts/generate_dependency_manifest.py`).
3. Review unknown, missing, copyleft, model-specific, and non-commercial terms (the current
   manifest flags 1 package — `espeakng-loader` — with no license metadata found at all).
4. Store the reviewed SBOM and full licence texts with the release evidence.

This notice is an inventory aid, not legal advice or a substitute for the
upstream licence texts.
